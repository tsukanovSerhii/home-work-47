# 🚀 React Hook Form Validation App

Проект, що демонструє використання бібліотеки **React Hook Form** для створення веб-форм із потужною вбудованою валідацією та управлінням станом.

![React](https://img.shields.io/badge/react-%2320232a.svg?style=for-the-badge&logo=react&logoColor=%2361DAFB)
![React Hook Form](https://img.shields.io/badge/React%20Hook%20Form-%23EC5990.svg?style=for-the-badge&logo=reacthookform&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/tailwindcss-%2338B2AC.svg?style=for-the-badge&logo=tailwind-css&logoColor=white)

## ✨ Реалізовані вимоги
- Проект на базі **Vite + React + TypeScript**.
- Використано **React Hook Form** для управління станом форми.
- **Вбудована валідація:** перевірка на обов'язковість, мінімальну довжину, паттерни електронної пошти та імені.
- Валідація відбувається в режимі `onTouched` (коли користувач покидає поле).
- Миттєве відображення помилок з відповідними підказками.
- **Сучасний дизайн (Glassmorphism):** Tailwind CSS v4.
- Анімація завантаження під час відправки форми (штучна затримка) та повідомлення про успіх.

## 📦 Встановлення та запуск

1. Клонувати репозиторій:
   ```bash
   git clone <ВАШЕ_ПОСИЛАННЯ>
   cd home-work-47
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Запустіть проект:
   ```bash
   npm run dev
   ```
